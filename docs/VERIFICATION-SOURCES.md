## 검증 케이스 5개 표준

각 계산기마다 다음 5케이스 입력 → 정부 결과 받음:
1. 일반 (디폴트값)
2. 경계 (낮은 소득/금액)
3. 경계 (높은 소득/금액)
4. 부양가족 많음 (해당 시)
5. 비과세/공제 적용 (해당 시)
