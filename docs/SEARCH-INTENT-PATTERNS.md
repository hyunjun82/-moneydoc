# 검색 의도 → 4섹션 매핑 템플릿

3개 패턴 중 하나로 분류 → 4섹션 구조 적용.

## 패턴 1: 즉답형 (계산 결과를 빠르게)

**대상**: 연봉 실수령, 적금 만기, 대출 이자, 퇴직금 등

**사용자 검색 패턴**:
- "{키워드} {숫자}" — 즉답 원함
- "{키워드} 표" — 한눈에 비교
- "{키워드} 변동 케이스" — 특수 상황
- "{키워드} 더 받는 법" — 절세/혜택

**4섹션 구조**:
```
01 [구간별 결과 표]
   - 입력값 구간별 (예: 연봉 3천~2억 1천만 단위)
   - 15~20행, 핵심 결과 1~2개 컬럼
   - 디폴트 조건 명시 (부양 1, 자녀 0 등)

02 [변동 케이스 FAQ 4~5개]
   - 받는 것 / 떼는 것 / 적용 안 되는 것 등
   - 실제 검색되는 의문 (성과급/이직월/퇴사월 등)

03 [결과 근거]
   - 산식 단계 (5~7단계)
   - 요율표 (4대보험, 누진세율 등)
   - 정부 출처 인용

04 [다음 단계: 절세/혜택 5가지]
   - 사용자가 즉시 실행 가능한 5개
   - 한도/조건 명시
```

**예시 (연봉 실수령액)**:
- 01: 연봉 3천~2억 월 실수령 표
- 02: 식대/성과급/조정신청/명세서차이 FAQ
- 03: 7단계 + 4대보험 요율표 + 출처
- 04: 비과세활용/IRP/주택청약/월세/의료비 절세팁

## 패턴 2: 의사결정형 (Yes/No 또는 옵션 비교)

**대상**: 양도세, 주담대 한도, 비과세 적금, 청약 1순위 등

**사용자 검색 패턴**:
- "{주제} 조건" — 자격 확인
- "{주제} 비교" — A vs B
- "{주제} 절세" — 시나리오 비교
- "{주제} 신고/신청" — 실행 절차

**4섹션 구조**:
```
01 [자격 체크리스트]
   - 대상 vs 비대상 명확히
   - Yes/No 결정 트리 또는 체크박스

02 [케이스별 결과 비교 표]
   - 옵션 A vs B vs C
   - 각 시나리오 세액/이득

03 [최적 전략 분석]
   - 절세 시나리오 (조건 변경 시 차이)
   - 산식 + 출처

04 [신고/신청 절차]
   - 기한, 필요 서류, 실수 사례
```

**예시 (양도세 1주택)**:
- 01: 비과세 5조건 체크 (보유 2년 / 거주 2년 / 12억 이하 등)
- 02: 1주택 vs 일시적2주택 vs 다주택 세액 비교
- 03: 장기보유특별공제 시나리오
- 04: 양도일 다음 달 말일까지 신고, 필요서류 5종

## 패턴 3: 자격 판정형 (정부 지원금)

**대상**: 실업급여, 자녀장려금, 기초연금, 청년월세 등

**사용자 검색 패턴**:
- "{지원금} 자격" — 받을 수 있나
- "{지원금} 얼마" — 금액
- "{지원금} 신청" — 어떻게 받나
- "{지원금} 거절" — 왜 안 됐나

**4섹션 구조**:
```
01 [자격 요건]
   - 소득/재산/연령/가구 기준
   - 표 형식으로 한눈에

02 [지급 금액 / 기간]
   - 입력값별 결과
   - 가구원 수별 차등 등

03 [신청 절차]
   - 시기, 방법, 필요 서류
   - 온라인 vs 오프라인

04 [거절/감액 사례 + FAQ]
   - 실제 못 받은 케이스 4~5개
   - 재심사 방법
```

**예시 (실업급여)**:
- 01: 자격 5요건 (180일 이상 / 비자발 이직 / 적극적 구직 등)
- 02: 평균임금 60% × 일수 (연령/근속별 표)
- 03: 워크넷 신청 → 고용센터 방문 → 구직활동
- 04: 자발 퇴직, 권고사직 거부, 재심사 청구

---

## 적용 절차

1. 계산기 정해지면 → 네이버 자동완성 + 연관검색어 캡처
2. 검색어 패턴 분석 → 패턴 1/2/3 중 하나 선택
3. 위 템플릿대로 4섹션 작성
4. JSON guide 구조에 매핑

## 금지 사항

- 모든 계산기에 같은 4섹션 적용 X (계산기마다 패턴 다름)
- 제목 "이 계산기 자세히 알아보기" 등 generic 금지
- "활용 팁" 같은 모호한 제목 금지 → "절세 5가지" 등 구체적으로
- FAQ 4개 미만 금지 (사용자 의문 충분히 안 풀림)
- 출처 표기 누락 금지 (EEAT)
