# 타이틀 생성 시스템 (KB Think 패턴 + 실측 검색어)

키워드 하나를 받아 → 실제 사용자가 검색하는 말로 → KB Think 톤의 타이틀을 뽑는 시스템.
허브+스포크 글 타이틀, 계산기 가이드 제목 모두 이 절차를 따른다.

---

## 1. 실측 검색어 수집 (Claude in Chrome)

타이틀은 머릿속에서 지어내지 않는다. **실제 검색어**에서만 뽑는다.

### 1-1. 구글 — 작동 O (메인 소스)

URL 패턴 (한국어·한국 지역 고정):
```
https://www.google.com/search?q={키워드}&hl=ko&gl=kr
```

시드 키워드를 의도별로 3~6개 돌린다: `{키워드}`, `{키워드} 조건`, `{키워드} 금액`,
`{키워드} 신청방법`, `{키워드} 계산`, `{키워드} 기간` 등.

각 페이지에서 Claude in Chrome `find`로 두 블록을 추출:
- **관련 질문 (PAA)** → `find "People also ask question rows"` → 질문형 타이틀 소스
- **관련 검색어** → `find "related search term links at bottom"` → 롱테일 키워드 앵커

예시 (실업급여 조건, 실측):
- PAA: "실업급여 받으려면 몇개월 근무?", "실업급여 신청하면 회사에 불이익?", "실업급여는 한 달에 얼마인가요?"
- 관련검색어: 2026 실업급여 조건 / 자발적 퇴사 실업급여 조건 / 실업급여 조건 나이 / 실업급여 금액 / 실업급여 기간 / 실업급여 신청 방법

### 1-2. 네이버 — 차단됨 → 폴백 필수

`search.naver.com`, `ac.search.naver.com`(자동완성), `m.search.naver.com` **전부 안전 제한으로 차단**.
Chrome·bash·python 어떤 경로로도 가져오지 못한다. 우회 시도 금지.

폴백 (둘 중 하나):
1. **사용자가 직접 복사·붙여넣기** — 네이버 검색창 자동완성 + 하단 연관검색어를 그대로 전달받아 앵커로 사용. (가장 정확)
2. 구글 관련검색어로 대체 — 네이버 데이터 없으면 구글만으로 진행하되, 보고에 "네이버 미반영" 명시.

## 2. 타이틀 패턴 (KB Think 70개 분석)

### 공통 법칙 (3개 모두 지킴)
1. **정확한 검색 키워드 + 의도어**(조건·신청 방법·한도·계산법·총정리)를 제목에 그대로 박는다. 클릭베이트로 풀어쓰지 않는다.
2. **연관 롱테일 2~3개**를 쉼표 또는 "~부터 ~까지"로 덧붙인다.
3. **꼬리는 자연스러운 질문**으로 닫는 경우가 많다.

### 포맷 (빈도순) — 변주해서 쓴다
| 포맷 | 예시 (KB 실측) |
|---|---|
| 질문형 (최다) | 자동차세 납부, 조회 어떻게 하나요? 연납 할인 받는 방법은? |
| 쉼표·"A부터 B까지" 나열 | 프리랜서 종합소득세 신고 대상부터 절세 전략까지 |
| 총정리·콜론(:) | 국내 주식 세금 총정리: 양도소득세, 배당소득세, 증권거래세 |
| "~란?" 정의형 | 퇴직연금이란? 종류, 계산법부터 DB형 DC형 차이까지 |
| 느낌표 훅! | 금리인하요구권 신청하고 대출 금리 줄이는 법! 조건부터 서류까지 |
| ㅣ(파이프) — 소수 | 주택연금 제도 개선ㅣ수령액 오르고 가입 문턱 낮아졌어요 |

### ㅣ(파이프) 규칙
KB는 **6~7개 중 1개꼴**로만 ㅣ를 쓴다. **남발 금지.** 한 세트(20여 개)에서 2~3개 이하.
나머지는 질문형·쉼표나열·총정리형으로 변주.

## 3. 키워드 → 타이틀 매핑 절차

1. 1번에서 모은 PAA·연관검색어를 **의도 클러스터**로 묶는다 (조건/금액·기간/신청·절차/주의/대상별).
2. 클러스터별로 롱테일 키워드 1개 = 스포크 타이틀 1개.
3. 각 타이틀에 2번 포맷을 **돌아가며** 적용 (같은 포맷 반복 X, ㅣ 최소).
4. 키워드는 제목 앞쪽에 그대로, 롱테일 sub는 뒤에 나열.

검증 체크:
- [ ] 정확한 검색 키워드가 제목에 살아 있나?
- [ ] 클릭베이트로 키워드를 지워버리지 않았나?
- [ ] ㅣ 비율이 전체의 10~15% 이하인가?
- [ ] 포맷이 한 종류로 쏠리지 않고 변주됐나?

---

## 4. 본문 소제목 = 타이틀과 정렬

소제목(h2/h3)은 타이틀에 쓴 검색어·질문과 **같은 말**로 단다.
타이틀이 "자발적 퇴사도 실업급여 받을 수 있을까?"면 본문 소제목도 "자발적 퇴사 실업급여, 받을 수 있는 정당한 사유"처럼 검색어를 반복. (검색의도-콘텐츠 정렬, EEAT)

---

## 5. 금지 사항
- 검색어 미수집 상태에서 타이틀 지어내기 금지 (반드시 1번 먼저).
- 키워드를 클릭베이트 문장으로 치환해 검색어가 사라지는 것 금지.
- ㅣ 남발 금지 (전 제목에 ㅣ = 오답).
- 한 포맷만 반복 금지 (질문형만, 또는 총정리만).
- 네이버 차단을 우회 시도 금지 → 폴백(사용자 복붙) 사용.
