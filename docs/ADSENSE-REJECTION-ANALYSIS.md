# 애드센스 거절 3회 원인 분석과 보강 작업표

기준: 2026-10-23 저장소(커밋 2686481)를 `npm run build` 로 빌드해 나온 202개 페이지를 전수 측정.
글자수는 헤더·푸터·내비·스크립트를 뺀 본문의 한글 글자 수. 측정 스크립트는 이 문서 끝에 있다.

## 1. 확인된 사실과 확인 못 한 것

확인된 것

- 1차 거절(2026-09-09) 원인은 고아 문서 63편. 09-10 커밋으로 수정. 지금 빌드에서 고아 문서 0건(`check-orphan.mjs`).
- 중복 title 0건. 중복 description 1건(/ 와 /404/). 미완성 자리표시 페이지 0건. 글끼리 같은 문장 겹침 거의 없음.
- 필수 페이지(소개·문의·개인정보·약관) 존재. ads.txt 존재. 애드센스 스크립트가 모든 페이지 head 에 있음.
- 실업급여 글 65편: 본문 중앙값 3,022자, 최소 1,281자(/unemployment/calculator/). 작성자·기준일 표시 있음.

확인 못 한 것 (사용자가 직접 확인해야 함)

- 2차·3차 거절 날짜. 1차 수정(09-10) 이후 며칠 만에 재신청했는지. 수정 직후 재신청이면 심사자가 수정 전 상태를 봤을 수 있다.
- 서치콘솔 '페이지' 보고서의 색인된 페이지 수. 사이트맵 199개 중 몇 개가 색인됐는지.
- 라이브 사이트가 이 빌드와 같은지 (이 환경은 외부 접속 불가).

## 2. 거절 원인 판정

1차 수정 뒤에도 두 번 더 거절됐다면 남은 원인은 링크가 아니라 **페이지 본문** 이다. 심사자가 홈에서 바로 들어가는 '인기 계산기' 8개와 카테고리 허브가 사이트에서 가장 얇다.

| 페이지 유형 | 개수 | 본문 중앙값 | 비고 |
|---|---|---|---|
| 계산기 | 64 | 1314자 | 그중 접힌 FAQ 안 347자. 펼쳐진 본문 969자. FAQ 답 평균 44자 |
| 가이드 글 | 98 | 3,000자대 | 문제 없음 |
| 카테고리 허브 | 10 | 639자 | 링크 목록만 있음 |
| 1,000자 미만 페이지 | 23 | | |
| 2,000자 미만 페이지 | 88 | | |

계산기 페이지가 '가치 없는 콘텐츠' 로 읽히는 구체적 모양:

1. 설명이 `<details>` 안에 접혀 있고 기본값이 닫힘. 심사자는 입력칸, 숫자 표, 닫힌 질문 제목 8줄만 본다.
2. 접힌 FAQ 답이 평균 40자 안팎의 메모체. 예: "단신 기준 월 약 354만. 4대보험 39만 + 소득세 24만 차감 후." (/salary/)
3. 계산기 64개 중 40개는 설명 글(/guide/)이 없다. 글 113편 중 65편이 실업급여 한 주제.
4. 계산기 페이지엔 작성자·기준일 줄이 없다. 글 페이지엔 있다.
5. 신뢰 표기 불일치: 퍼센트·나이·날짜·할부·현금서비스 계산기에 '정부 공식 산식' 배지. 홈은 '66종 오차 0', 소개는 '외부 대조 대출 7종'.
6. 개인정보처리방침이 '향후 Google AdSense 도입 예정' 이라고 적혀 있는데 스크립트는 이미 전 페이지에 있음. 갱신일 2026-05-09.
